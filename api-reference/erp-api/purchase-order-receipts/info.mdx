---
title: "Purchase Order Receipts"
---
A purchase order receipt records goods received against a parent [purchase order](/api-reference/erp-api/purchase-orders/get-item). It is a first-class resource with its own id, sync, and endpoint — the parent is linked via `purchase_order_id`. Each line item joins back to the source purchase-order line via `line_item_id`, and may carry lot/bin detail for lot- or bin-tracked items. A line booked into several lots or bins appears once per lot and bin, so the same `line_item_id` can repeat; `receipt_line_item_id` is unique within the receipt. Some ERPs, such as Linnworks, accept new receipts but cannot list or return them afterwards; there the list and single-receipt endpoints return `501`, so keep the response from the create call.
