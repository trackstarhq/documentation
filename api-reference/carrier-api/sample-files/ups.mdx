## Overview

UPS invoices come from the UPS Billing Center as a CSV and a PDF per invoice. Each CSV row is a single charge: a shipment with a base freight charge, a fuel surcharge, and a tax becomes three rows that share the same `Tracking Number` and `Invoice Number`. The columns cover shipment identification, package details, charges, sender/receiver/third-party addresses, customs data (for international shipments), and freight-forwarding metadata.

## Files you'll receive

Trackstar archives both files for every invoice on the account and on any UPS billing plan the login can see. Each has its own entry in the [Files](/api-reference/carrier-api/files/info) API.

| File | `file_name` | Format | Notes |
| :--- | :---------- | :----- | :---- |
| Invoice CSV | `Invoice_<invoice number>_<MMDDYY>.csv` | Comma-delimited, UTF-8, `\n` line endings | UPS sends the CSV without a header row. Trackstar adds the 250 column names below as the first row; the values are not changed. |
| Invoice PDF | `Invoice_<invoice number>_<MMDDYY>.pdf` | PDF | The invoice as UPS prints it. UPS often publishes the PDF a day or more after the CSV, so it can show up in a later sync than its CSV. |

UPS chooses the file name, which carries the invoice number and the invoice date. Plan invoices are named by plan number instead of invoice number. A plan number repeats every billing period, so the date is what tells two plan invoices apart. When UPS sends a download as a zip, Trackstar unpacks it and archives the CSV or PDF inside, so you never receive a zip.

## Shape notes

- **250 names, 270 values on account invoices.** Account invoice CSVs downloaded since August 31, 2026 have 270 values per row, whatever the invoice date; ones downloaded earlier have 250. UPS does not publish names for the last 20, so the header row Trackstar adds still has 250 names and each data row has 20 more values than the header. So far those 20 columns have always been empty. Plan invoice CSVs are still 250 values wide. If you read the file with a header-keyed CSV reader, expect the extra values to land under an unnamed key.
- **Multi-row shipments.** Expect 2–5 rows per `Tracking Number`, one per charge type.
- **Net vs. gross.** `Net Amount` is what the customer paid for the charge. `Incentive Amount` is the discount; `Net Amount + Incentive Amount = gross charge before discount`.
- **Charge types are coded.** The `Charge Classification Code` column contains a 3-letter code (`FRT`, `FSC`, `ACC`, `TAX`, etc.). Trackstar maps these to the descriptions listed under [Mapping to invoice line items](#mapping-to-invoice-line-items).
- **Two date formats.** `Transaction Date` is usually `YYYY-MM-DD`, but some US charge rows use `MM/DD/YYYY`. Trackstar converts both to ISO 8601 in `transaction_date`.
- **Account-level charges have no transaction date.** Miscellaneous charges billed to the account rather than to a shipment leave `Transaction Date` blank. Trackstar uses `Invoice Date` for those rows.
- **International columns.** The majority of columns (`Customs Number`, `Duty Amount`, `VAT Amount`, etc.) are only populated for international shipments. Most domestic US rows leave them empty.
- **Place Holder columns.** `Place Holder 46`–`48` and `Place Holder 50`–`59` are empty columns reserved by UPS. There is no `Place Holder 49`; that position holds `SCC Scale Weight`.

## Mapping to invoice line items

Each CSV row becomes one invoice line item.

| Trackstar field | Source | Notes |
| :-------------- | :----- | :---- |
| `id` | `Lead Shipment Number` | Rows that share a lead shipment number get a `-1`, `-2`, ... suffix in the order they appear. A row with no lead shipment number gets a generated ID. |
| `tracking_number` | `Tracking Number` | |
| `invoice_id` | `Invoice Number` | |
| `account_id` | `Account Number` | |
| `transaction_date` | `Transaction Date` | Falls back to `Invoice Date` when blank. `MM/DD/YYYY` values are converted, and the time is set to midnight UTC. |
| `charge_description` | `Charge Classification Code` | Mapped from the code, not taken from the `Charge Description` column: `FRT` Transportation Charges, `FSC` Fuel Surcharges, `ACC` Accessorial Charges, `TAX` Taxes, `GOV` Government Charges, `BRK` Brokerage Charges, `EXM` Exemptions, `MSC` Miscellaneous Charges, `INF` Informational. A blank code gives `Data Unavailable`; any other code gives `Unknown Charge Type`. |
| `net_cost` | `Net Amount` | |
| `gross_cost` | `Net Amount` + `Incentive Amount` | `Basis Value` is not used. |
| `raw` | The full row | Keyed by the 250 column names. The 20 unnamed trailing values are left out. |
